# 検討経緯: 共有会話の要約（2026-10）

撮影システムの方向性を決めた、claude.ai での音声会話の要約。転載ではなく要約で、主な結論と理由を残す。ここで決まった方針は [DESIGN.md](../../DESIGN.md) に反映している。

## 出発点と目標

- 出発点は「Raspberry Pi Camera V3 で Canon EOS R6 の画質に勝ちたい」
- センサーサイズの差（小指の爪ほど vs フルサイズ）があるので、汎用の撮影で勝つのは難しい
- そこで用途を **壁にハンガーで掛けた洋服の物撮り** に絞った。被写体が動かないことを最大の武器にして、Web 掲載なら R6 と見分けがつかない水準を目指す

## 画質の基本方針

- 効く順に三つ: **照明**（光の量と面の大きさで小さいセンサーを補う）、**低感度でじっくり撮る**（固定して長めの露光）、**RAW (DNG) で撮って後処理**
- お金をかける順番は **照明 → 撮影の手間（枚数）→ カメラ本体**

## 撮影技法

- **HDR**: カメラ内蔵の HDR より、露出を変えて 3〜5 枚撮り enfuse などで合成するブラケット撮影を推した。生地の白飛びと影のディテールを両立できる
- **超解像**
  - 候補は AI 超解像（Real-ESRGAN など）とマルチフレーム超解像の二つ
  - **AI 超解像は採らない**。「それっぽく作る」技術で、フリマや EC では実物とのギャップがクレームにつながるため
  - **マルチフレーム超解像に絞る**。少しずつズレた約 10 枚を重ね、1 枚では取りこぼす画素の隙間の情報を、実際に撮った光で埋める
- **フォーカススタッキング**: ピントを少しずつずらして撮り、シャープな部分だけを合成する。ハンガー掛けの服は襟と裾で奥行きがあるので効く。AF を持つカメラを選ぶ理由になる
- **キャリブレーションボード**: 実物どおりの色が狙いなので、カラーチェッカーが最もリターンが大きい。チェッカーボードやドットパターンは、歪みや解像の検証用になる
- **合成**: OpenCV で行う。ECC や特徴点で位置合わせする。最初は「位置合わせして平均するだけ」（ノイズが大きく減る）から始める

## 微動（ズレ）の作り方

- 段階的に検討した: 服を数ミリずらす → 服をずらすとシワや陰影の形が変わって合成に不利 → **カメラ側を XY スライダーで動かすのが理想形**
- 自動化する: ステッピングモーターとドライバ（A4988 / DRV8825、後に TMC2209 を推奨）を GPIO から制御し、「動かす → 撮る」を繰り返す
- 動かした直後は微振動が残るので、0.5 秒ほど待ってから撮る
- **回転でもよい**
  - パン・チルトの小さな回転なら、画像上は平行移動とほぼ同じになる。レンズ中心まわりに回せば視差も出ない
  - ロール（光軸まわり）は画面中心が動かないので不可
  - 回転では画面の端が台形に歪むので、OpenCV のホモグラフィ（`findHomography`、ECC のホモグラフィモード）で位置合わせする
- ズレ量が正確でなくてもよい。合成側でズレを測るので、ランダムな微小ズレでも効く
- **会話の時点での結論**: サーボの雲台キットは 1° 単位くらいで粗すぎて、超解像の微動には向かない。おすすめは NEMA17 ＋ リードスクリュー（T8）のリニアステージ、TMC2209 ドライバ、モーター用の 12V 別電源
  - → その後パンチルト B0283 を用意したので、使えるかを検証することにした（[DESIGN.md](../../DESIGN.md#パンチルト微動の検証計画)）

## 機材選定

- **カメラ**
  - 会話の結論は「V3 のまま照明に投資するのが一番安い」
  - 比較した候補: HQ カメラ（センサーが大きく C マウント）、Arducam 64MP、Arducam IMX519（16MP・AF・バランス型）、M12 レンズ交換型
  - → 最終的に **IMX519** を採用した（V3 より画素が多く、AF があるのでフォーカス制御ができる）
- **カメラ 2 台は使わない**。Pi 4 のカメラポートは 1 つで、マルチプレクサなどを足すと配線・同期・合成が面倒になる。服は動かないので 1 台でアングルを変えれば足りる
- **Raspberry Pi AI Camera（Sony IMX500）は使わない**。被写体を判断するためのカメラで、高画質向けではない。センサーサイズも V3 と同程度
- **照明**
  - 予算は約 2 万円
  - 会話の推奨: 2 灯を左右斜め前に置き、主光と弱めの補助光にする。光源は服より一回り大きい面にする。2 灯の色温度を揃え、CRI の高いものにする。背景は白かグレーの無地（約 3000 円）
  - Ulanzi の 40W COB や、AL60 エアチューブ（縦長で服に合うが、1 本 2 万円前後で 100W PD 給電が要る）も検討した
  - → 最終的に **NEEWER NL-192AI ×2** を採用した（[neewer-nl-192ai.md](../hardware/neewer-nl-192ai.md)）
- **お試し**: 最初は手元の Web カメラで「位置合わせ＋平均」の効果を確かめる案が出た。Web カメラはピント固定が多いので、フォーカススタッキングは試せない

## V3 についての補足（参考）

- Camera Module 3 のレンズは固定式で、焦点距離は約 4.7 mm、f/1.8 程度。AF はレンズ自体を前後に動かす
- 広角なので、近づきすぎると服の端が歪む。少し距離を取って撮る
